КАК ЗАПУСТИТЬ
1. AutoHotkey v1.1 (НЕ v2): https://www.autohotkey.com/  (раздел "Download v1.1")
   Запуск с лаунчером: дважды щёлкнуть Launcher.ahk (или собранный AdminHelper.exe), в окне нажать "Запустить скрипт".
   Запуск как раньше, без лаунчера: main.ahk (лаунчер и его настройки тогда недоступны).
2. Все файлы лежат в одной папке и называются ТОЧНО так (без _1, _abc123 и т.п.):
   main.ahk, AutoSAMP.ahk, Sp.ahk, SpecCalib.ahk, QueueGui.ahk, Theme.ahk, MiniWin.ahk, Launcher.ahk, LauncherGui.ahk
   (они подключают друг друга по имени; с другими именами будет ошибка #Include)
3. Запусти игру, затем main.ahk (от администратора, если игра запущена от админа).

ПОСЛЕ ОБНОВЛЕНИЯ ИГРЫ (если Alt+2/3/4 и античит ведут себя странно)
Ctrl+Alt+F8 - диагностика (что скрипт видит)
Ctrl+Alt+F9 - калибровка ID спека: /re за игроком -> F9 -> ввести его ID;
              то же ещё за 1-2 другими игроками. Результат в offsets.ini.

СБОРКА В EXE
Запустить Build.bat - получится AdminHelper.exe (внутри все .ahk, включая лаунчер). Нужен AutoHotkey v1.1 с компилятором Ahk2Exe.
Вручную: Ahk2Exe, Source = Launcher.ahk, Base File = "Unicode 32-bit", Convert.
offsets.ini и queue_window.ini при этом лежат рядом с exe (нужны права на запись в папку).

ОКНО ОЧЕРЕДИ (Numpad0)
Двойной клик / Взять - взять игрока; Спек - только /re; Скип - убрать.
Num5/Num6 работают как раньше.
Пока смотришь за взятым игроком, QueueGui сам читает чат-лог: выход -> 'вышел', кик античитом -> 'кикнут античитом', кик системой (Verification error и др.) -> 'кикнут системой',
краш -> 'краш/обрыв связи', наказание админом за чит -> 'чит, наказан'; кик 'Выдана блокировка' -> 'наказан'. При взятии пишет локально 'Слежу за ...'.
Пока ты в спеке за взятым игроком: как только в чате появится строка про его кик системой - в /a уйдёт 'кикнут системой', про выход - 'вышел' (в любой момент, не только первые 5 секунд). Если игрок вышел с пометкой '(краш/обрыв связи)' - пишется 'краш/обрыв связи'.
В окне: ползунок - прозрачность, список - закрепить окно в углу/на краю экрана, кнопка 'Закрепить здесь' - в любом месте, A-/A+ - шрифт.
Настройки лежат в queue_window.ini. Ширина колонок: потяни границы в заголовке (обычный режим) - запомнится навсегда.
'Прозрачный фон' (кнопка или Ctrl+Numpad0) - режим HUD: белый текст на прозрачном фоне и ползунок, кнопки появляются при наведении;
окно двигается Ctrl + левая кнопка мыши. Если что-то пошло не так - Ctrl+Numpad0 вернёт обычное окно.
xN в колонке - сколько раз ник попадал в очередь за сессию.

ЛАУНЧЕР (Launcher.ahk / AdminHelper.exe)
Окно с вкладками: Главная, Окно очереди, Мини-окно, Тема, Система. Внизу "Применить" - сохраняет настройки в queue_window.ini
и сразу перерисовывает окно очереди и мини-окно (запускать скрипт заново не нужно).
Главная: "Запустить скрипт" / "Перезапустить" (очередь сбрасывается) / "Остановить" (скрипт останавливается, лаунчер остаётся),
  кнопки открытия окна очереди и мини-окна, автозапуск скрипта через N секунд после появления процесса игры,
  "прятать лаунчер в трей после запуска". Закрыть окно крестиком - уйдёт в трей, скрипт продолжит работать.
  Открыть настройки снова: двойной клик по значку в трее или Ctrl+Alt+F10 (работает и из игры).
Окно очереди: прозрачный фон, прозрачность, размер шрифта, закрепление, сброс размера окна и ширины колонок.
Мини-окно: показывать / скрыть, прозрачность, через сколько секунд цифры становятся жёлтыми и красными, сброс размера и места.
Тема: готовые темы (фиолетовая, синяя, графит, зелёная, бордо) и 8 цветов вручную (hex или палитра), перекрашивает все окна.
Система: запуск лаунчера с Windows, запрос прав администратора, имя процесса игры, быстрые кнопки "открыть папку / ini / лог".
Закрытие лаунчера (кнопка "Закрыть" до запуска скрипта или "Выход" в меню трея) выключает и скрипт - они работают в одном процессе.
Новые ключи ini: [mini] WarnSec, BadSec; [launcher] AutoWait, AutoDelay, HideOnStart, GameExe, RunAsAdmin.

МИНИ-ОКНО СЧЁТЧИКА (Ctrl+Numpad9)
Маленькое окно поверх игры: 'AC 3 · RE 1' (AC - античит, RE - Reconnect). Цвет цифр: серый - очередь пуста,
зелёный - записи свежие, жёлтый - есть запись старше минуты, красный - старше трёх минут.
Размер меняется мышью (потяни за край, шрифт подстроится), двигается за заголовок. Клик по окну - открыть/закрыть основное окно.
Правая кнопка мыши - меню: основное окно, прозрачность (100/85/70/55/40 %), размер по умолчанию, скрыть.
Размер, место, прозрачность и 'показывать при запуске' запоминаются в queue_window.ini, раздел [mini].

ТЕМА И РАЗМЕР ОСНОВНОГО ОКНА
Фиолетовая тема по умолчанию. Цвета лежат в queue_window.ini, раздел [theme], формат RRGGBB (можно с #):
Bg (фон окна), Panel (список и панели), Accent (кнопки), Text (текст), Dim (неактивный текст), Ok / Warn / Bad (зелёный / жёлтый / красный).
Поменял цвет в ini - перезапусти скрипт. Удалить раздел [theme] - вернётся фиолетовая тема по умолчанию.
Основное окно можно растягивать мышью, размер запоминается отдельно для обычного режима (W, H) и для прозрачного (TW, TH).
Кнопки в обычном режиме - свои плоские (цвет Accent). В прозрачном режиме внешний вид прежний: белый текст без фона.

ФАЙЛЫ
main.ahk      - античит-очередь (Num5/6/7/8), Alt+2/3/4, Alt+P (погода), F12, XButton2
AutoSAMP.ahk  - библиотека чтения памяти (подключается из main.ahk)
Sp.ahk        - sendChat / addChatMessageEx / getSpID ... (подключается из main.ahk)
SpecCalib.ahk - диагностика и калибровка ID спека (подключается в конце main.ahk)
QueueGui.ahk  - окно очереди античита, Numpad0 (подключается в конце main.ahk)
Theme.ahk     - цвета (фиолетовая тема), тёмный заголовок окон (подключается из QueueGui.ahk)
MiniWin.ahk   - мини-окно со счётчиком очереди, Ctrl+Numpad9 (подключается из QueueGui.ahk)
Launcher.ahk  - точка входа лаунчера: показывает окно, ждёт запуска, потом подключает main.ahk
LauncherGui.ahk - окно лаунчера и настроек, значок в трее (подключается из Launcher.ahk)
Build.bat     - сборка AdminHelper.exe из Launcher.ahk
Анти-капс удалён.

fastask.ahk (хотстринги) - по желанию: добавь в САМЫЙ КОНЕЦ main.ahk строку
#Include fastask.ahk

ПОСЛЕ ЗАМЕНЫ ФАЙЛОВ скрипт нужно перезапустить (Num- или закрыть и запустить main.ahk заново), иначе работает старый код.
Проверка версии: при взятии игрока в чате пишется 'Слежу за ... [QueueGui v20 launcher]'.

Если что-то не отписалось: пришли файл queue_debug.log (лежит рядом со скриптом) - там видно, что скрипт увидел в чате и почему решил не писать.
Слежение работает и для игрока из очереди, за которым ты в спеке не через Num5 (по строке 'Вы начали следить за ...').

БЫСТРЫЕ ОТВЕТЫ (пока следишь за игроком из очереди, чат закрыт): Numpad1 - 'норм', Numpad2 - 'лосс', Numpad3 - 'пинг', Numpad4 - 'лосс + пинг'.
Ответ уходит как '/a ID текст' (для Reconnect - '/a [Reconnect] ID текст'), после чего цель закрывается.
Если чат открыт - цифры нумпада печатаются как обычно. Автоотписи (вышел/кик/бан) при открытом чате: скрипт проверяет эхо в админ-чате,
а если чат открыт - на миг закрывает его, отправляет, открывает снова и возвращает набранный текст. Каждое сообщение уходит один раз.


МИНИ-ОКНО (ОБНОВЛЕНО)
Вкладка «Мини-окно» позволяет независимо задавать ширину, высоту, прозрачность, гарнитуру и размер шрифта. Растягивание окна мышью меняет только его геометрию, не масштабируя текст. Положение и текущий размер сохраняются автоматически. Для немедленного применения нажмите «Сохранить и применить».
